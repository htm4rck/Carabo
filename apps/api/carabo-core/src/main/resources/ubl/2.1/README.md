# OASIS UBL 2.1 schemas

These unmodified XSD files come from the normative OASIS UBL 2.1 release:
https://docs.oasis-open.org/ubl/os-UBL-2.1/UBL-2.1.html

Included are the common schemas and the Invoice, CreditNote and DebitNote main
schemas needed by Carabo. The copyright and redistribution terms are preserved
inside the original XSD files.
